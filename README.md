Chronvyr —— Lightweight & Transparent Desktop Schedule Widget for Windows.
Built with WinUI 3 & Windows App SDK, focusing on low memory, always-on-top glanceable calendar, local-only agenda & full personalization.

Chronvyr 告别传统臃肿日历与网页式小组件，以现代 Windows 原生架构WinUI3重构桌面日程体验：像一束柔和微光贴在桌面，想看就看、想改就改，安静后台运行不抢性能、
不占视觉空间，让每一次时间规划都轻快而优雅。无论是学生备考、职场规划还是日常作息管理，Chronvyr 都用最克制的设计，帮你专注当下、掌控每一天。

目前的功能：
日历（会拉取节假日信息）
日程 设定目标起始和截止时间
日记 随手记下灵感
番茄钟 开始专注
工作台 可视化看清自己的进度
桌面组件：
日程表
日记栏
胶囊栏：类似于灵动岛，可以点击展开子页面，内容除了日程日记和工作台和番茄钟，还有剪切板历史，硬件监控，天气显示
